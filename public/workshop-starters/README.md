# イベント用スターター素材

ジャンルごとの画像は `public/workshop-starters/{genre}/assets/` にあります。

- shooting … 宇宙船3種 + 敵3種
- athletic … キャラ3種 + 地形・コイン・ゴール
- puzzle … ぷよ5色 + おじゃま

体験ページの ZIP ダウンロード時に、選んだジャンルの assets がフォルダに同梱されます。

## 素材画像（2026-10-03 更新）

全19枚を、背景にアルファ透過を持つPNGとして作り直しました。
ファイル名と素材パスは従来どおりです。体験ページの素材プレビューと
スターターZIPは同じ画像を参照します。

- シューティング: 上向きロケット3色、エイリアン3色
- アスレチック: 右向きキャラクター3種、足場、ブロック、ゴール旗、コイン
- パズル: ジェリー状の駒5色、灰色のおじゃま駒

生成には組み込み画像生成ツールを使用しています。
生成プロンプトと透過確認結果は `output/workshop-assets/` に保存します。
