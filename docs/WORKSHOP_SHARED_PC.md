# PC共用の体験ワークショップ運用

## 進行

- 講師と参加者が、同じステップを一緒に進める。
- 制作とサイト操作はPCで行う。スタッフは各画面上部の「スタッフ用 · 次の参加者へ」から交代する。
- 自動の時間切れリセットは行わない。

## 体験中の一時保存

名前、ダウンロードしたフォルダー情報、ジャンル別の素材選択・進捗、ステップ別のお願い文・確認チェックを、同じタブの sessionStorage に保持する。サーバーや長期保存用の localStorage には保存しない。

モーダルを閉じた場合や再読み込みでも復元する。素材変更は該当する素材のパス・名前等だけを更新し、参加者が追記した内容を維持する。アレンジ例を押した場合は、その例にお願い文を置き換える。

## クール交代

1. 前の参加者の作品保存・公開URLを確認する。
2. 前の制作フォルダーとAntigravityのチャットを閉じ、次の参加者が新しいフォルダー・チャットを使えるように準備する。
3. 「スタッフ用 · 次の参加者へ」を押し、確認欄2つにチェックする。
4. 「リセットして次の参加者へ」で、このタブの全ジャンルの参加者状態を消し、入口に戻る。

キャンセルでは何も消さない。ファイルのダウンロード準備・アップロード中はリセット不可。公開済み作品、管理者の認証情報、PC上のファイル、Antigravityのチャット、クリップボード、他のタブはリセット対象外。

スタッフ用は運用上の表示で、認証やPINによるアクセス制限は設けていない。交代時はスタッフが操作する。共用PCでは体験用タブを1つに統一し、複製した古いタブを残さない。

## 確認済みの操作

- お願い文を編集して素材を変えても追記が残る。
- 閉じて開き直す・再読み込みでお願い文とチェックを復元する。
- 交代画面のキャンセルでは編集を保持する。
- 確認チェックなしではリセットできない。
- 交代確定で入口に戻り、名前・進捗・選択・下書きを初期化する。
