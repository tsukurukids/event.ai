# 体験ワークショップ UX点検（2026-10-03）

前提：PCを親子で操作し、講師と同じステップを進め、クール交代時はスタッフがリセットする。

## 評価と修正

|優先度|問題・参加者への影響|対応|
|---|---|---|
|高|一覧の大番号とStep番号が違い、口頭案内で迷う|準備／1〜5／発表に統一。完了後も番号を保持|
|高|完了で次の画面が自動表示され、講師の案内を追い越す|準備・制作の完了後は一覧へ戻る|
|高|先のステップを開くだけで以前のステップが完了色になる|実際の完了データだけで色を決定|
|高|コピーが長い説明の下に埋もれる|編集欄の上に配置し、スクロール時も追従|
|高|例文で自分の工夫が即上書きされる|置換を明記し、置換前へ戻す操作を追加。復元元もタブ内に一時保存|
|中|保存方式や技術的説明が主作業に割り込む|補足を開閉式にし、コピー後の行動を短く案内|
|中|最初の未完了を黄色で推奨し、先生の現在の案内と混同する|自動の次ステップ強調を撤去|

本文・入力18px、補足16pxへの拡大は前回対応済み。スタッフの交代ボタンと確認手順は維持。

## 検証

ブラウザーで番号、完了後の一覧復帰、例文置換→復元、再読み込み後の復元を確認。PC画面でコピーと編集欄の配置を目視確認。Vite本番ビルドを実施。

## 次に観察する点

実参加者による利用テストは未実施。Antigravityへの切り替え、ZIP解凍、フォルダー選択は別アプリにまたがるため、授業リハーサルで迷う箇所と所要時間を確認する。スタッフのリセットは外部アプリ・ダウンロード済みファイル・他タブを消さないため、交代手順と合わせて運用する。
